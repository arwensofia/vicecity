## What this means for the runtime

- Hardware access is concentrated in a few libraries, so the runtime can replace those
  libraries' functions wholesale (high-level emulation) instead of emulating registers.
- The 65 syscalls are the kernel API the runtime must implement (threads, semaphores,
  interrupt handlers, SIF/IOP RPC, cache ops).
- Graphics reaches the GS through DMA packets that RenderWare's `sky2` driver builds,
  with VU1 microcode doing transform/lighting. Two options: emulate VU1+GS (like PCSX2),
  or replace RenderWare's PS2 render pipelines with a Metal renderer at the
  atomic/world-sector level. This is the main architecture decision.
- Game code uses VU0 macro instructions heavily (~1,900, mostly vector/matrix math);
  these translate directly to NEON. Only 16 `vcallms` sites need VU0 micro mode.
